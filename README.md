# Tina Liu 作品集

純 HTML／CSS 靜態網站，不需建置。

- `index.html`：首頁（作品、關於我、經歷、聯絡）
- `work/*.html`：其他作品案例頁（用藥提醒App直接寫在首頁）

- `assets/img/`：作品圖片（由 Figma 匯出）
